# ts-launch-blueprint

A TypeScript port of [py-launch-blueprint](https://github.com/smorinlabs/py-launch-blueprint) — a
batteries-included template for launching new projects with a strong developer-experience,
CI, release, and open-source-readiness baseline.

This repository is the container for that port. It currently holds only the porting process
and will be filled in via tested vertical slices.

## Status

🚧 Not started. This repo is scaffolding only.

The port follows the phased process in
[`typescript_port_process_prompt.md`](./typescript_port_process_prompt.md):

1. `TS_PORT_INDEX.md` — catalog every source file and its embedded intent
2. `TS_EXISTING_REPO_REVIEW.md` — capture prior TypeScript/Bun/CI/release decisions from existing repos
3. `TS_PORT_RESEARCH.md` — choose idiomatic TypeScript/Node equivalents
4. `TS_PORT_PLAN.md` — phased, vertical-slice implementation plan
5. `TS_PORT_LOG.md` — record what actually changed during implementation
